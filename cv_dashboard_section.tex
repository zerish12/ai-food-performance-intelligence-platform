\section*{Interactive Analytics Platform}

\textbf{AI-Powered Food Performance \& Recommendation Intelligence Platform}

\begin{itemize}
    \item Built an interactive Streamlit and Plotly dashboard integrating Python, SQLite, machine learning, behavioural analytics, QC/NIR monitoring, experimentation, and recommendation optimisation.
    \item Developed executive KPI views for cancellation, repeat order rate, flavour switching, satisfaction, complaint rate, and unified food performance score.
    \item Created interactive recipe scorecards, customer behaviour analytics, recommendation-version evaluation, QC/NIR anomaly intelligence, and customer feedback analytics.
    \item Trained machine learning models for churn prediction and food performance score prediction using customer, dog, recipe, behavioural, and quality-control variables.
    \item Built an AI-style recommendation engine that evaluates eligible recipes for a selected dog profile and recommends the recipe predicted to maximise food performance.
    \item Added a scenario simulator to estimate the impact of recommendation improvements and quality-control interventions on cancellation, repeat ordering, and satisfaction.
    \item Designed the platform as a business-facing decision-support tool for Product, Food, Engineering, Analytics, and leadership stakeholders.
\end{itemize}
